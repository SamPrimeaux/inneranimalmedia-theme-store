# Revise — Editorial Commerce

Revise 0.1.2 preserves the five-page Fuel & Free Time compiled storefront and ships the matching editable CMS project. Home, Products and Collections use the Home, product and collection template types. The Collections template retains the /ideas/ demo route.

The CMS project uses the original page sections, shared Announcement Bar, Header and Footer, and separate primary and secondary hero button blocks. Product, account and checkout services require their respective host integrations.

The Theme Store owns this compiled snapshot and versioned release. The AgentSam installer owns site-scoped drafts.
